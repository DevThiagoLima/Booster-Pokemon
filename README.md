# Booster Pokémon

Aplicação web desenvolvida em React + TypeScript que simula a abertura de boosters de cartas Pokémon utilizando uma API externa para buscar os dados das cartas dinamicamente.

---

## 🚀 Tecnologias Utilizadas

- React
- TypeScript
- Vite
- React Router DOM
- CSS
- PokéAPI / Pokémon TCG API

---

## 📂 Estrutura do Projeto

```bash
src/
├── assets/
├── components/
├── pages/
├── services/
├── types/
├── App.tsx
├── main.tsx
```

---

## ✨ Funcionalidades

- Abrir boosters de cartas Pokémon
- Exibir cartas obtidas dinamicamente
- Navegação entre páginas
- Sistema de rotas
- Consumo de API externa
- Interface responsiva
- Tratamento de loading e erros
- Componentes reutilizáveis

---

## 🔗 API Utilizada

O projeto utiliza APIs públicas relacionadas ao universo Pokémon:

- https://pokeapi.co/
- https://pokemontcg.io/
